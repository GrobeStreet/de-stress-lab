# JOSS readiness

The technical submission bundle is prepared in `paper/`, but the project is not
yet eligible for JOSS screening. The detailed reviewer mapping is maintained in
[`REVIEW_CHECKLIST.md`](REVIEW_CHECKLIST.md).

JOSS currently treats all four of the following as pre-review gates: more than
six months of public development, demonstrated research impact, good
open-source practice, and iterative development over time. This repository
became public on 2026-07-21. The earliest conservative submission date is
therefore **2027-01-22**, provided the intervening history shows real
maintenance, releases, issues, pull requests, feedback, and research use.

Before submission:

- [x] OSI-approved license
- [x] installable Python package
- [x] automated tests and continuous integration
- [x] usage and API-oriented documentation
- [x] contribution, support, and conduct guidance
- [x] changelog and explicit governance/maintenance expectations
- [x] JOSS `paper.md` and bibliography
- [x] required AI usage disclosure
- [x] deterministic canonical archive and published checksum manifest
- [x] archived reusable-package release with a verifiable DOI:
  `10.5281/zenodo.21633731`
- [ ] six months of public development history
- [ ] evidence of use beyond the original flagship analysis
- [ ] independent installation by another researcher
- [ ] author confirms affiliation, ORCID if desired, and conflict-of-interest declaration

An independent-install report can be filed through the repository issue form
or added to [issue #21](https://github.com/GrobeStreet/de-stress-lab/issues/21).

The reusable software release is archived separately from the frozen flagship
scientific reproduction. Cite `10.5281/zenodo.21633731` for the installable
software toolkit and `10.5281/zenodo.21632602` for the immutable v1.0 cosmology
reproduction package.

Submitting before every pre-review gate is met would invite a predictable desk
rejection and is intentionally deferred. Under JOSS's current AI policy, the
author must also handle editor and reviewer conversations without generative-AI
assistance after submission.
