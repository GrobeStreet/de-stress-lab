# PRD submission declarations

## Data availability

All inputs used in the compressed-likelihood analysis are public releases from
DESI, SDSS/eBOSS, Pantheon+/SH0ES, DES, and Planck. Retrieval provenance,
machine-readable result manifests, scripts, and the frozen reproduction
package are available in the public repository and at
<https://doi.org/10.5281/zenodo.21632602>. This work reimplements published
compressed likelihoods and does not contain a raw-data reanalysis.

## Code availability

The canonical source, tests, frozen results, and prediction ledger are
available at <https://github.com/GrobeStreet/de-stress-lab>. The reusable
Python package is available from PyPI as `de-stress-lab==0.1.0` and its
versioned software archive is <https://doi.org/10.5281/zenodo.21633731>.

## AI assistance

AI systems assisted with implementation, literature triage, testing, and
drafting. Their outputs were treated as fallible work product and checked
against executable tests, primary sources, frozen manifests, and adversarial
software/statistics reviews. AI-assisted checks are not represented as
independent scientific review or human replication. The named author accepts
responsibility for the submitted text, analysis, and citations.
