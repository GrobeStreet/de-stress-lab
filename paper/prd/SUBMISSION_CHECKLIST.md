# Physical Review D submission checklist

## Completed

- [x] Research Article selected as the intended article type.
- [x] Canonical scientific PDF frozen and archived.
- [x] Scientific reproduction DOI published and verified.
- [x] Reusable package published on PyPI and archived under a separate DOI.
- [x] Public source, tests, provenance, and result manifest available.
- [x] Cover letter drafted.
- [x] Data and code availability statements drafted.
- [x] AI-assistance disclosure drafted.
- [x] Scope distinguishes compressed-likelihood work from raw-data reanalysis.
- [x] Selection, LRG2, full-CMB, and clean-room caveats retained.

## Scientific gates

- [ ] Complete the blind human clean-room execution and preserve the signed
  verifier worksheet.
- [ ] Reconcile the submission manuscript against `RESULTS_MANIFEST.json`
  after the human run without changing the frozen scientific archive.
- [ ] Obtain scoped technical comments from two readers and log corrections.
- [ ] Decide whether the unresolved official-likelihood LRG2 reconstruction is
  completed or explicitly deferred in the submitted version.

## Author-only declarations

- [ ] Confirm the submitted author name and correspondence email.
- [ ] Confirm “independent researcher” as the intended affiliation.
- [ ] Confirm ORCID inclusion or intentional omission.
- [ ] Confirm funding statement.
- [ ] Confirm competing-interest statement.
- [ ] Confirm that the manuscript is not under consideration elsewhere.
- [ ] Confirm that no recommended or excluded referees should be supplied.

## Submission-server actions

- [ ] Create or use an existing APS submission account; do not create one
  automatically.
- [ ] Upload the final manuscript PDF and source files.
- [ ] Enter the data-availability statement.
- [ ] Complete authorship, ethics, funding, conflict, and AI-use declarations.
- [ ] Review the generated submission proof.
- [ ] Author explicitly presses the final submission control.

The package is not to be represented as submitted until APS returns an
accession code.
