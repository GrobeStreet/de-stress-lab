# Automated Reproducibility Audit

Get an evidence-backed review of one research-software repository for a

[Purchase the audit through Stripe](https://buy.stripe.com/5kQbJ08uh8ZFaCpfXu3F600)

## What is included

- a rerun of the transparent 100-point repository-readiness scan;
- static review of the package, build, test, CI, dependency, and release setup;
- inspection of determinism, provenance, citation, and result-freezing controls;
- a prioritized discrepancy and remediation list;
- a Markdown findings report and machine-readable JSON result;
- an installation or test smoke check when the repository can be executed
  safely in an isolated environment.

The target is delivery within two business days after the repository and its
documented build instructions are accessible. If safe execution is not
possible, the report identifies the blocker and completes the static review.

## Fixed scope

The price covers one customer-authorized repository, one primary build path,
and publicly available or explicitly authorized materials. The repository URL
entered at checkout is required.

Do not submit credentials, unpublished data, private access tokens, personal
records, or regulated information through Stripe or a public GitHub issue.
Private-repository access, if accepted, is arranged separately and minimally.

## What is not included

This audit does not:

- certify that scientific claims are correct;
- provide peer review, legal advice, security certification, or regulatory
  assurance;
- reproduce an entire paper or rerun expensive domain-specific simulations;
- include major code changes, a correction pull request, or statistical
  red-team experiments.

Those activities require a separately scoped reproduction sprint or
statistical red-team engagement. Findings are reported whether they strengthen
or weaken the original claim.
