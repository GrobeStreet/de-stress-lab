# Changelog

All notable changes to the reusable `de-stress-lab` package are recorded here.
The scientific reproduction and its frozen result artifacts have separate
version records under `archive/`.

This project follows [Semantic Versioning](https://semver.org/).

## Unreleased

- Add a reviewer-facing JOSS checklist, governance policy, and structured
  independent-installation report form.
- Clarify the current JOSS eligibility and external-evidence gates.

## 0.1.1 - 2026-07-29

- Add the dependency-light `destress audit-repo` command and reusable GitHub
  Action for structural reproducibility checks.
- Publish the package to PyPI using trusted publishing.
- Archive the reusable software release at DOI
  [10.5281/zenodo.21633731](https://doi.org/10.5281/zenodo.21633731).
- Separate reusable-software citation metadata from the immutable flagship
  scientific reproduction archive.
- Remove the commercial audit funnel from the public research repository.

## 0.1.0 - 2026-07-27

- First reusable Python-package release.
- Add typed grouped BAO likelihoods and an explicit CPL cosmology model.
- Add deterministic multistart optimization, deletion-influence summaries,
  empirical selected-tail calibration, and frozen-ledger verification.
- Add tests on supported Python versions, JOSS paper builds, contributor
  guidance, and the first versioned prediction ledger.
