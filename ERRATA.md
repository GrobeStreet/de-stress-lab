# Errata and release clarifications

## Zenodo DOI statement in the v1.0 whitepaper

The v1.0 whitepaper's Appendix B says the repository was “Archived with DOI via
Zenodo.” That sentence described the intended archive state, but no verifiable
Zenodo DOI had been minted when v1.0 was released. The repository and GitHub
release were public at that time.

The v1.0 PDF and source are retained unchanged as frozen release artifacts.
On 2026-07-27, the exact canonical archive, PDF, and checksum manifest were
published without modifying the tag or release assets. The version DOI is
[10.5281/zenodo.21632602](https://doi.org/10.5281/zenodo.21632602), and the
all-versions DOI is
[10.5281/zenodo.21632601](https://doi.org/10.5281/zenodo.21632601). The DOI
statement therefore became true after release; it was not true at the original
publication timestamp.
