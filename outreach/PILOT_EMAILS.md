# Pilot outreach messages

## UC San Diego OSPO

**Subject:** Complimentary reproducibility audit for one UCSD open-source research project

Hello UC San Diego OSPO team,

I am an independent researcher in the Encinitas area developing an open,
non-executing reproducibility-readiness audit for public research-software
repositories. It checks release integrity, tests, documentation, provenance,
licensing, citation metadata, and archival readiness without running the
repository's code.

Would OSPO be willing to nominate one public UCSD research project for a
complimentary pilot audit? The maintainers would receive the full report and
prioritized fixes with no obligation to endorse, cite, or purchase anything. I
would especially value criticism of the rubric and any false positives.

The flagship demonstration, source, and methodology are public:
https://github.com/GrobeStreet/de-stress-lab

If this is outside OSPO's scope, no response is necessary.

Best,
Bobby Morong

## UC San Diego cosmology group

**Subject:** Complimentary static reproducibility audit for a public cosmology repository

Hello,

I am an independent researcher near UC San Diego. I built a public reproduction
and selection-aware stress test around the DESI DR2 compressed likelihoods, and
then generalized its release and provenance checks into a static repository
audit.

I would like to offer your group one complimentary audit of a public analysis
repository you choose. The audit does not execute the code and does not judge
the scientific conclusion; it reports reproducibility readiness, provenance,
release integrity, and concrete remediation items. There is no request to
endorse my mathematics or the DESI interpretation.

Project and methodology:
https://github.com/GrobeStreet/de-stress-lab

Corrections and skeptical feedback are welcome. If the offer is not useful, no
response is necessary.

Best,
Bobby Morong

## Computational research center or lab

**Subject:** No-cost pilot audit of one public research-software repository

Hello,

I am offering a small number of complimentary reproducibility-readiness audits
to San Diego computational research groups. The audit is static and
non-executing. It freezes the reviewed commit and checks documentation, tests,
environments, provenance, licensing, archival metadata, and release integrity.

Would your group like to select one public repository for a pilot? You would
receive both machine-readable and concise reports, with no obligation to
endorse or purchase anything. I am looking for technically demanding feedback
and evidence that the method generalizes beyond its cosmology demonstration.

Methodology and source:
https://github.com/GrobeStreet/de-stress-lab

Best,
Bobby Morong
